# GitHub Pages / Medium import package

This folder is the equation-free article version of **Asynchronous Agentic Orchestration at Scale**.

It contains:

- `index.html` — publish this directly with GitHub Pages.
- `article.md` — editable article source.
- `style.css` — lightweight page styling.
- `assets/figures/` — the complete experimental figure set converted to PNG for browsers and Medium.

There are no equation images, no MathJax, no LaTeX, no `.github` directory, no `.gitignore`, and no hidden files.

For GitHub Pages, publish the repository root from the `main` branch. After the Pages URL is live, use Medium's **Import a story** feature and paste that URL. Medium should then import the prose and ordinary PNG figures without depending on equation rendering.
